# שאלון משפחות חדשות → טלגרם

כל מילוי של השאלון שולח הודעה לטלגרם: סיכום התשובות, טיוטת וואטסאפ, וכפתור שפותח את הצ'אט עם הטקסט מוכן.

הסקריפט רץ אצל גוגל על שליחת הטופס. אין שרת, והבוט לא מאזין ולא עונה לאף אחד.

## התקנה

1. בגיליון התשובות של הטופס: תוספים → Apps Script, מדביקים את `apps-script/Code.gs`.
2. Project Settings → Script properties:
   - `TELEGRAM_TOKEN`
   - `CHAT_ID`
3. בטלגרם לוחצים Start אצל הבוט פעם אחת. הוא לא יענה.
4. מריצים `setup`, ואז `installTrigger`.

הטוקן לא נשמר בקוד.

## התאמה לטופס

ב-`CONFIG`, `NAME_QUESTION` ו-`PHONE_QUESTION` חייבים להיות זהים לכותרות השאלות, כולל נקודתיים. `{{name}}` ב-`WA_TEMPLATE` מתחלף בשם המשפחה.

אחרי שינוי בקובץ הזה צריך להדביק שוב ל-Apps Script ולשמור. הריפו לא מעדכן את העותק שרץ.

מספר נייד ישראלי מתקבל גם עם רווחים, מקפים או קידומת `+972` / `00972`. קווי או מספר לא תקין מגיעים בלי כפתור, עם הסבר מה נכשל.
